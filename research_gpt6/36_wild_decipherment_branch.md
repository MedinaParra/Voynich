# Wild Decipherment Branch

Status: HYPOTHESIS GENERATION / NOT A TRANSLATION

## Purpose

This branch is deliberately independent from the confirmatory TimesFM and lexical-anchor program. Its goal is to ask a different question: if we temporarily stop trying to classify the manuscript and instead try to infer what individual recurring Voynich tokens could *do*, can we generate candidate meanings that later survive blind tests?

No candidate gloss is accepted because it sounds plausible. Every hypothesis must eventually predict unseen contexts.

## Core idea: constraint-satisfaction decipherment

Treat each frequent Voynich token as an unknown variable rather than as a word to translate directly. Infer constraints from six independent channels:

1. **Visual object constraint** — labels adjacent to plants, stars, containers, bodies, tubes, etc.
2. **Distributional constraint** — neighboring tokens, line position, paragraph position, repetition and morphology.
3. **Cross-section recurrence** — the same token/family appearing in herbal, pharmaceutical, zodiac, astronomical or recipe contexts.
4. **Morphological constraint** — recurring prefixes/suffixes/stems must behave consistently rather than receiving a new meaning on every page.
5. **Procedural-language constraint** — test whether running text behaves like operations + quantities + materials/objects rather than ordinary prose.
6. **Medieval-language compatibility** — only after structural candidates exist, compare them against historically plausible lexicons/languages. Language resemblance cannot create the candidate by itself.

## Double-perspective test

Every proposed reading must be attacked simultaneously from two incompatible perspectives:

- Perspective A: Voynichese encodes linguistic/semantic information.
- Perspective B: Voynichese is generated by a non-semantic, pseudo-textual, cipher-like, mnemonic or highly constrained process.

A phenomenon counts as evidence only when A predicts it substantially better than B under an explicit null model.

## First target

Do not translate paragraphs. Build a small `candidate dictionary` from object labels and recurring morphological families. For each candidate token/family record:

- EVA form;
- folios and loci;
- object/section contexts;
- prefix/stem/suffix decomposition candidates;
- distributional neighbors;
- competing semantic hypotheses;
- competing non-semantic explanation;
- falsification test;
- status: NOT_RUN / PASS / FAIL / BLOCKED.

## First unconventional hypothesis to test

**Relational lexicon hypothesis:** many Voynich labels may not be nouns naming the pictured object. They may encode a *property, preparation state, part, use, celestial relation, or operation*. This could explain why attempts to map plant drawings directly to plant names repeatedly fail.

Prediction: label families should recur across visually different objects when those objects plausibly share a functional/property class, while nearby running text should reuse the same morphological component in compatible syntactic positions.

Competing null: recurrence is explained entirely by section/Currier/hand/quire and generic token frequency.

## Stop conditions

A candidate meaning is rejected if it requires ad-hoc exceptions, disappears after Currier/hand/quire controls, cannot predict held-out contexts, or depends on choosing a historical language after seeing the target.

Translation claim remains UNKNOWN until multiple independent anchors converge and predict unseen material.
