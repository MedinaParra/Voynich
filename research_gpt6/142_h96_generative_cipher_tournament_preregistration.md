# H96 — Generative Cipher Tournament preregistration

Status: **PASS (preregistration only)**

## Purpose
Prospectively test whether broad generative mechanism families can reproduce a frozen multiscale structural signature of Voynichese without claiming plaintext, language, semantics, translation, or decipherment. H96 is a model-class falsification experiment, not a decoding attempt.

## Scientific motivation and firewall
H91 established reproducible visual object↔label geometry, while H92–H95 failed prospectively to establish simple visual↔lexical mappings. Therefore H96 does not add another post-hoc visual lexical endpoint. It moves to an independent question: which generative mechanism classes, if any, can reproduce multiple textual constraints simultaneously?

The primary score and PASS rule are frozen here before H96 code is added or H96 results are inspected. No family, endpoint, weight, threshold, or holdout may be added/removed after execution begins.

## Data and holdout
Use the repository's frozen canonical Takahashi transcription as the primary source. Folios are sorted by canonical folio identifier. Compute SHA-256 over the exact normalized input consumed by H96 and record it in the artifact.

A deterministic folio holdout is defined without inspecting lexical statistics: SHA-256(`H96-HOLDOUT-20261010|<folio_id>`), interpreted as an unsigned integer; the lowest 20% of eligible folios by this hash are the holdout, the remainder development. Ties break lexicographically. The holdout membership and its hash MUST be emitted before any model fitting/evaluation. No folio can move between partitions.

Eligibility: folios with >=20 normalized tokens. Token normalization must reuse an existing frozen repository normalization routine where available; otherwise H96 = BLOCKED pending a separately preregistered normalization repair.

## Frozen mechanism families
Exactly these six null/candidate families compete:
1. **IID unigram** — tokens independently sampled from the development token-frequency distribution.
2. **First-order token Markov** — token generated from previous-token transition distribution with frozen additive smoothing 1e-6.
3. **Character Markov-2** — tokens generated by a second-order character model including explicit BOS/EOS boundaries.
4. **Slot resampler** — empirical prefix/core/suffix slot resampling using a deterministic three-way split at character positions floor(L/3), floor(2L/3); empty slots allowed. This is a structural generator, not a semantic morphology claim.
5. **Homophonic-expansion surrogate** — map each development character to one of two latent aliases with probabilities proportional to its observed odd/even-position usage; generate latent Markov-2 text and collapse aliases back to observed characters. This tests whether a simple state-free homophonic expansion can reproduce the signature.
6. **Folio-state Markov-2** — two latent folio states obtained only from development folios by deterministic k-means (k=2, random_state=96001, n_init=100) on frozen nonsemantic folio statistics [mean token length, token-type ratio, character entropy]; fit a separate character Markov-2 generator per state. Holdout state assignment uses nearest frozen development centroid. This is a latent-state mechanism, not an identification with Currier A/B.

If a family cannot be implemented exactly as specified, that family = BLOCKED and overall H96 = BLOCKED; do not silently substitute another model.

## Frozen generated sample size and seeds
For every family generate exactly 200 synthetic replicas of each evaluated partition, preserving the real partition's folio token counts. Base RNG seed = 20261010. Family seeds = 96001..96006 in the order listed above; replica seed is `family_seed + replica_index`.

## Frozen multiscale signature
For real and synthetic corpora compute exactly these eight statistics:
1. mean token length;
2. token-length standard deviation;
3. token type/token ratio;
4. character unigram Shannon entropy;
5. character bigram conditional entropy H(C_t|C_{t-1});
6. fraction of repeated adjacent tokens;
7. median within-folio first-half vs second-half Jensen-Shannon divergence of character unigram distributions;
8. median Jensen-Shannon divergence between consecutive folios in canonical order.

No label-object endpoint is included in the primary score because H92–H95 already falsified the prespecified simple lexical-anchor family; H91/H92–H95 remain external constraints in interpretation.

## Frozen scoring
Fit/evaluate family parameters on development only. For each statistic j, use the 200 development synthetic replicas to estimate synthetic median m_j and robust scale s_j = max(MAD_j, 1e-9). Development discrepancy is sum_j |real_j-m_j|/s_j and is descriptive only.

The confirmatory holdout statistic uses the already-fitted family without refitting. Generate 200 holdout replicas. For each of the eight holdout statistics calculate the two-sided empirical central 99% interval using the 0.5th and 99.5th percentiles of the synthetic distribution.

A family **PASS**es H96 only if the real holdout value lies inside the frozen 99% synthetic interval for **all 8/8** statistics. Otherwise that family = **FAIL**. No averaging can rescue a failed endpoint. This deliberately stringent intersection rule tests simultaneous reproduction.

Overall H96 = **PASS** iff at least one preregistered family PASSes all 8/8 holdout constraints and its mandatory controls below pass. Overall H96 = **FAIL** if all six families execute and none passes. Overall H96 = **BLOCKED** if required data/provenance/implementation prevents complete evaluation. H96 = **NOT_RUN** before a real execution.

## Mandatory controls
- **Determinism:** rerunning the same family/seed must reproduce the exact JSON statistics hash.
- **Partition firewall:** no holdout token/string/frequency may be used to fit family parameters; only holdout folio IDs and token counts may be known for sample-size preservation before evaluation.
- **Length-count preservation:** every synthetic folio must contain exactly the observed number of tokens for the corresponding folio.
- **Degeneracy:** a generated family with >5% empty tokens or nonfinite primary statistics = FAIL.

## Output/provenance
Artifact MUST include executing commit SHA, source path and SHA-256, runner SHA-256, exact development/holdout folio IDs and partition hash, family definitions, seeds, all eight real statistics, all synthetic medians/intervals, endpoint pass masks, family PASS/FAIL/BLOCKED, controls, and overall status. Do not emit inferred plaintext or translations.

## Interpretation ceiling
A family PASS would mean only that this model class can reproduce this frozen eight-statistic holdout signature under H96. It would not establish that the Voynich Manuscript was generated by that mechanism, identify a cipher/key, identify a language, recover semantics, or decode any text. A FAIL eliminates only the exact tested implementation/parameterization, not every possible member of the broad historical cipher family.

Semantics = **NOT_RUN**. Language = **NOT_RUN**. Translation = **NOT_RUN**. Decipherment = **NOT_RUN**.
